# dreamapps.it.com

Лендінг Dream Apps — один самодостатній файл `index.html`. Ніякої збірки: логотип, стилі,
скрипти та переклади 30 мовами вбудовані всередину.

## Хостинг

Netlify, домен `dreamapps.it.com` (реєстратор Namecheap). Publish directory — корінь
репозиторію, build command порожній (див. `netlify.toml`). Після під'єднання репозиторію
кожен пуш у `main` викочується автоматично.

## Правки

Редагується безпосередньо `index.html`:

- **Переклади** — об'єкт `langs` у `<script>` внизу файлу, 30 мов. Порядок у меню задає
  `LANG_ORDER`, мови з написанням справа наліво перелічені в `RTL`.
- **Додатки** — картки в секції `#apps`. Коли додаток вийде в Google Play, замініть рядок
  `badge_soon` у всіх мовах і оберніть картку посиланням на сторінку Play.
- **Політика конфіденційності** — секція `#privacy` унизу сторінки. На цю адресу
  (`https://dreamapps.it.com/#privacy`) посилається Google Play Console, тому якір `#privacy`
  чіпати не можна.

## Перевірка перед деплоєм

Відкрити файл у браузері й переконатися, що:

- перемикач мов показує всі 30 і пошук по них працює;
- арабська перемикає сторінку в RTL;
- перемикач теми працює в обидва боки;
- на вузькому екрані відкривається бургер-меню.
